GitHub 加速下载

—

为源码压缩包与 Release 资产链接配置加速前缀。右键菜单中的主菜单项使用「默认前缀」。

新增前缀

末尾斜杠可省略，保存时会自动归一为单个「/」。

已配置前缀

通过各加速前缀实际下载该文件，测出首包延迟与下载速度。首次测速会请求访问对应前缀域名的权限。

    尚未配置任何前缀，当前使用内置兜底前缀。

    生效范围

    • /{owner}/{repo}/archive/... 源码 zip / tar.gz / tgz
    • /{owner}/{repo}/releases/download/... Release 资产
    • /{owner}/{repo}/releases/latest/download/... 最新版资产
    • 其他普通链接不会被注入菜单项，也不影响原有行为

    链接转换测试

    仅做本地拼接预览，不会发起请求。
